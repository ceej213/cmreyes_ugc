# cmreyes_ugc

One-page UGC creator portfolio for CJ Reyes.

- `index.html` is the page. Open it directly or serve it with GitHub Pages.
- `Main.dc.html` and `Desktop.dc.html` are the design-canvas artboards the page is generated from. `canvas.json` lays them out.
